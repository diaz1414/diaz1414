## // 03. ENGINEERING PROTOCOLS

1. **Bare Essentials First:** Hindari library berlebihan. Jika cukup diselesaikan dengan native HTTP handler atau 20 baris bash script, jangan pasang package 50MB.
2. **Deterministic Uptime:** Mengutamakan health-check otomatis, isolated worker processes, dan restart policies ketat pada tiap container.
3. **Bandwidth & Cache Discipline:** Aset statis, manifest m3u8, dan redirect token wajib diproses di edge/proxy sebelum menyentuh origin server.
4. **No Slop, No Sugarcoating:** Dokumentasi dan log harus eksplisit tanpa metafora abstrak atau klaim marketing kosong.
